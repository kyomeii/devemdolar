# Notas pra agentes de IA / Notes for AI agents

- Site: Astro + Starlight. Conteúdo em `src/content/docs/{pt,es,en}/`, mesmo nome de arquivo nos três idiomas.
- `pt` é a versão original. Ao mudar `pt`, atualize `es` e `en` mantendo o tom (informal, grosso, engraçado) — não suavize.
- Links internos sempre com prefixo de idioma: `/pt/...`, `/es/...`, `/en/...`.
- Configuração editável (URL, repo, carteiras, contato) em `src/config.mjs`.
- Rode `npm run build` antes de entregar. Dev server: `npx astro dev --background`.
- Nunca adicione links de afiliado, cursos ou mentorias.
