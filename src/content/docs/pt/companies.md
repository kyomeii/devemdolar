## Plataformas de talentos (nearshore)

Você faz um processo seletivo com a plataforma, e eles te apresentam pra empresas gringas. Geralmente pagam menos que contratação direta, mas é a porta de entrada mais fácil.

| Plataforma | O que é |
|---|---|
| [Revelo](https://www.revelo.com) | Brasileira, conecta devs da América Latina com empresas americanas |
| [Strider](https://www.onstrider.com) | Brasileira, mesma ideia, foco em devs |
| [Toptal](https://www.toptal.com) | Rede de freelancers "top 3%", processo seletivo pesado |
| [Turing](https://www.turing.com) | Plataforma de devs remotos, muito vaga de IA/treinamento de modelos |
| [Arc.dev](https://arc.dev) | Vagas remotas e freelas pra devs |
| [Andela](https://www.andela.com) | Começou na África, hoje contrata na América Latina também |
| [Lemon.io](https://lemon.io) | Freelas pra startups |
| [BairesDev](https://www.bairesdev.com) | Nearshore argentina gigante, contrata muito brasileiro |

## Sites de vagas remotas

| Site | Observação |
|---|---|
| [HiringCafe](https://hiringcafe.com) | Agregador direto dos ATS. O melhor, na minha opinião |
| [Wellfound](https://wellfound.com) | Antigo AngelList, vagas de startup |
| [We Work Remotely](https://weworkremotely.com) | Um dos mais antigos de vaga remota |
| [Remote OK](https://remoteok.com) | Muita vaga, filtra por "worldwide" |
| [Remotive](https://remotive.com) | Curado, menos lixo |
| [Himalayas](https://himalayas.app) | Dá pra filtrar por país que a empresa aceita |
| [Working Nomads](https://www.workingnomads.com) | Agregador de vagas remotas |
| [Get on Board](https://www.getonbrd.com) | Focado em América Latina |
| [Remotar](https://remotar.com.br) | Brasileiro, vagas remotas (nem todas pra gringa) |
